# 🚀 Portafolio Profesional & Dev Sandbox

<h3 align="center">Full Stack Developer (Stack MERN) & Analista de Datos</h3>



---

## 🌟 Resumen del Proyecto

Portafolio web interactivo de alto rendimiento desarrollado con enfoque en diseño minimalista premium estilo **Apple Pro / Liquid Titanium**, micro-interacciones avanzadas, efectos de física en tiempo real y una **Terminal CLI Interactiva** con más de 25 comandos.

---

## 🛠️ Stack Tecnológico Principal

### 🌐 Frontend & Experiencia de Usuario
- **HTML5 Semántico & CSS3 Moderno:** Variables CSS nativas, glassmorphism, flexbox, CSS Grid y micro-animaciones fluidas.
- **JavaScript Moderno (ES6+):** Arquitectura modular sin dependencias pesadas externas.
- **React.js:** Componentes modulares, Hooks y renderizado reactivo.
- **Canvas API:** 
  - `AntigravityEngine`: Simulación física cuántica de partículas reactivas al cursor con dispersión elástica.
  - Motor de partículas de confeti procedural.
- **Web Audio API:** Sintetizador de efectos sonoros procedurales en tiempo real para clics, tecleo de terminal y eventos.

### ⚙️ Backend & Base de Datos
- **Node.js & Express.js:** APIs RESTful modulares, middlewares de seguridad, CORS, compresión y enrutamiento asíncrono.
- **MongoDB & Mongoose:** Modelado de datos NoSQL, esquemas atómicos e indexación.
- **Autenticación & Seguridad:** Tokens JWT (JSON Web Tokens), hashing seguro y validación estricta de rutas.

### 📊 Análisis de Datos & Business Intelligence
- **Python:** Análisis y transformación de datos con **Pandas** y computación numérica con **NumPy**.
- **Microsoft Power BI & DAX:** Modelado dimensional de negocios, métricas financieras (TIR, VAN, Break-even) y tableros ejecutivos interactivos.
- **SQL:** Consultas estructuradas (PostgreSQL / MySQL) y optimización relacional.

## ✨ Características y Efectos Destacados

### 🪪 1. Credencial Interactiva con Física de Lanyard (`LanyardBadge`)
- Simulación de una credencial de conferencias colgante suspendida por un hilo gris titanio.
- **Física de arrastre elástica:** Permite arrastrar la tarjeta con el cursor o en pantallas táctiles con inercia, balanceo gravitacional y retorno elástico.

### 🖥️ 2. Terminal Interactiva Dev Sandbox (`alexis-sh`)
Emulador de terminal interactiva con historial mediante flechas de navegación ($\uparrow$ / $\downarrow$) y barra de 27 botones de acceso rápido:

| Categoría | Comandos Disponibles |
| :--- | :--- |
| **💥 Efecto Especial** | `sabotear` / `sabotear codigo`: Provoca un colapso visual de gravedad donde toda la página cae hacia abajo, enviando al usuario al inicio para observar el derrumbe y reconstruyéndose automáticamente en 3 segundos. |
| **💼 Perfil & Carrera** | `skills`, `projects`, `bio`, `contact`, `cv`, `mern` (arquitectura ASCII). |
| **🎮 Easter Eggs & Hacks** | `antigravity`, `matrix`, `hack`, `coffee`, `joke`, `quote`, `cat`, `roll`, `rickroll`, `git`, `dance`, `weather`, `calc [expr]`, `ping`, `whoami`, `sudo`, `secret`. |
| **⚙️ Sistema** | `theme` (conmutador Dark/Light), `clear` (limpiar pantalla). |

### 💊 3. Barra de Navegación ReactBits (*Pill Navigation*)
- Cápsula deslizante dinámica con seguimiento de cursor y *ScrollSpy* sincronizado con las secciones:
  $$\text{INICIO} \longrightarrow \text{BIOGRAFÍA} \longrightarrow \text{TERMINAL} \longrightarrow \text{PROYECTOS} \longrightarrow \text{CONTACTO}$$
- Menú lateral responsivo optimizado para dispositivos móviles.

### ✨ 4. Border Glow Líquido Apple Pro
- Iluminación specular reactiva que se activa estrictamente en el contorno exterior de las tarjetas y la terminal al pasar el cursor, eliminando manchas o destellos invasivos.

## 💼 Proyectos Destacados en el Portafolio

1. **Plataforma E-Commerce MERN:** Catálogo reactivo, carrito de compras dinámico, checkout seguro, autenticación JWT y panel de administración integral.
2. **Sistema de Gestión de Turnos:** Plataforma de reserva de citas en tiempo real con prevención de solapamientos y control de roles.
3. **Punto de Venta (POS) & Control de Stock:** Facturación rápida, control atómico de inventario y balances de caja diarios.
4. **Análisis de Viabilidad de Negocio:** Modelado financiero en Python y Power BI con evaluación de viabilidad (VAN, TIR y punto de equilibrio).
5. **Dashboard de Análisis de Ventas & Clientes:** Tablero ejecutivo con segmentación RFM, análisis de tendencias y retención de clientes.

## 🚀 Puesta en Marcha Local

### Prerrequisitos
- [Node.js](https://nodejs.org/) (versión 16 o superior).

### Instalación y Ejecución

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/alesi01/miportafolio.git
   cd miportafolio
   ```

2. **Iniciar el servidor local:**
   ```bash
   node server.js
   ```

3. **Abrir en el navegador:**
   Ingresa a [http://localhost:3000](http://localhost:3000).

## 🔒 Seguridad & Privacidad

El repositorio incluye un archivo [`.gitignore`](.gitignore) configurado para resguardar la privacidad y seguridad:
- Exclusión de variables de entorno (`.env*`) y claves de acceso (`secrets/`, `*.key`, `*.pem`).
- Bloqueo de fotos personales y documentos de identidad (`personal-photos/`, `*dni*`, `*passport*`).
- Servidor HTTP con protección contra *Directory Traversal* y bloqueo de archivos del sistema.
